How the 4-Stage Offline Ingestion & Analysis Pipeline Works
1. Ingestion
Extracts 1-based frame numbers, protocols, TCP flags, and DNS events into SQLite.
2. Features & Rules
Evaluates 20s tumbling host windows against port scan, brute force, DNS, and egress rules.
3. ML Anomaly
Isolation Forest scores 9-feature host vectors against the 99th-percentile baseline threshold.
4. Correlation
Union-Find groups related alerts and computes a 0–100 heuristic prioritization score.
