How Isolation Forest Scoring Works, 9-Feature Schema & Methodological Boundaries

Ordered 9-Feature Vector (log1p + StandardScaler fitted on 101 training windows only):

1. unique_dst_ports 2. unique_dst_ips 3. failed_flow_ratio 4. max_flows_same_target 5. dns_query_count 6. avg_qname_length 7. nxdomain_ratio 8. bytes_out_external 9. out_in_ratio
  • Calibration ≠ Testing: The 49 calibration windows set the 99th-percentile threshold ({{ "%.4f"|format(model_meta.threshold) if model_available else '0.5978' }}) and are not a test set.
  • 99th-Percentile Threshold ≠ Guaranteed 1% Unseen FPR: Calibrating at the 99th percentile cuts off the top 1% of calibration windows; on the 65 held-out benign windows, the observed false-positive rate was 3/65 = 4.62%.
  • Complementary Coverage: Moderate single-feature shifts (such as brute_force.pcap score 0.4400 and exfiltration.pcap score 0.5668) remain below the multivariate tree threshold and are caught by deterministic rule detectors.
