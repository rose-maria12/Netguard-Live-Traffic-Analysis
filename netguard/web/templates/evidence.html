How to Verify NetGuard Findings in Wireshark
  1. Locate the alert below and verify the original PCAP SHA-256 digest.
  2. Copy either the Trigger-Direction Wireshark Display Filter (initiator → target) or the Bidirectional Investigation Filter (includes SYN-ACK, RST, and DNS replies).
  3. Open the corresponding PCAP/PCAPng file in Wireshark, paste the filter into the display filter bar, and inspect the exact matching frame numbers.
