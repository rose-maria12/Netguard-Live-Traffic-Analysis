How Windows Defender Firewall Enforcement & Host Protection Work
  • Inbound Host Firewall Scope: Rules are created on the local Windows Defender Firewall using New-NetFirewallRule -DisplayName "NetGuard-Block-<IP>-<TS>" -Direction Inbound -Action Block -RemoteAddress "<IP>".
  • Self-Lockout & Infrastructure Protection: Loopback (127.0.0.0/8), link-local (169.254.0.0/16), multicast, unspecified, all local host adapter IPs, and configured gateways/DNS resolvers are automatically rejected before OS execution.
  • Offline & Replay Isolation: Uploaded PCAP files and Sample Replay sessions are strictly isolated from automated firewall containment; only live interface captures in auto mode or explicit analyst actions can create firewall blocks.
