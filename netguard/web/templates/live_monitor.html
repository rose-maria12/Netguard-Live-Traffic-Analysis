How Live Capture, Sample Replay & DNS Activity Work
  • Live Capture vs. Sample Replay: Live Capture sniffs frames from the selected network adapter via Npcap/Scapy and writes a rolling PCAP file in captures/. Sample Replay streams packets from a local test PCAP through the same normalization queue while keeping automatic Windows Firewall blocking disabled.
  • Queue & Pause Semantics: Packets enter a bounded 10,000-packet queue and are evaluated every 20 seconds (and flushed immediately on Stop). While paused, arriving packets are ignored.
  • DNS Activity vs. Website Visits: DNS Events record UDP/TCP port 53 lookups, mDNS (UDP 5353), and LLMNR (UDP 5355). A DNS lookup indicates name resolution activity (including background OS/browser prefetching) and does not by itself prove an interactive website visit.
