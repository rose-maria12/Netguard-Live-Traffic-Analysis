How NetGuard's Dual-Engine Pipeline Works (Heuristics, Isolation Forest & Correlation)

NetGuard processes network traffic in 20-second tumbling windows across four stages: (1) Packet & Flow Reconstruction indexes 1-based Wireshark frame numbers, bidirectional 5-tuple flows, and DNS transactions; (2) Rule Detectors evaluate port scanning, SSH/RDP brute-force patterns, DNS tunneling/DGA, and outbound volume ratios; (3) Isolation Forest ML scores 9 multivariate host-window features against a 99th-percentile threshold (0.5978) calibrated on CIC-IDS2017 Monday benign traffic; (4) Incident Correlation groups alerts via Union-Find (same source or victim-to-source pivot within 300s) and computes a 0–100 prioritization score.

Note on Behavioral Indicators: Heuristic alerts (such as high outbound-to-inbound byte ratios during browser uploads) are network indicators for analyst review, not automatic proof of host compromise.
